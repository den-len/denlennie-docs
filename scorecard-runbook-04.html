Scorecard funnel runbookSTEP 04

Redirect the legacy pages.

Anyone holding an old link, in an email, a bookmark or a browser history, should land on the new denlennie.com pages, not the legacy ones on thescalemethodbook.com.

System GHL (the account that owns thescalemethodbook.com) Time About 15 minutes You need Steps 01–03 completed · GHL admin access

The redirect map

Steps

  1. In GHL, go to Settings → Domains → URL Redirects for the sub-account that owns thescalemethodbook.com.
  2. Add the five redirects from the map above. Type: permanent (301). Match the path exactly as listed.
  3. Test each one in a private browser window by visiting the old URL and confirming you arrive at the new denlennie.com page. Test both https://thescalemethodbook.com/... and https://www.thescalemethodbook.com/...; if only one works, add the redirect for the other host too.
  4. Do NOT delete the old funnel steps or pages inside GHL. Redirects make them unreachable; keeping them for a month is free insurance.

Done when

  • All five old URLs land on the matching new pages, on both www and non-www.
  • The old funnel pages still exist inside GHL (redirected, not deleted).

If something goes wrong

  • GHL's redirect tool refuses the path or loops: remove the redirect, confirm the old page works again, and message Den rather than experimenting on a live domain.
  • You cannot find URL Redirects in this sub-account: the domain may be managed at agency level. Check the agency view, or message Den.
