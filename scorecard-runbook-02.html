Scorecard funnel runbookSTEP 02

Repoint the quiz.

Switch the assessment quiz's redirects from thescalemethodbook.com to the new on-site result pages, and fix the small inconsistencies around the quiz. This is the step that actually stops the leak.

System Lovable (denlennie.com project) Time About 20 minutes You need Step 01 live first + Prompt 7 from the prompt pack

Before you start

  1. Confirm all five result pages are live by opening them in a normal browser (not the Lovable preview). If any 404s, go back to Step 01.
  2. The quiz lives in a single file, public/scale-quiz-embed.html. Three things in it must NOT change: the 15 questions, the name and email capture, and the webhook call that sends the lead into SceneOps. The only thing changing is where finishers get sent.

Steps

  1. Paste Prompt 7 from the prompt pack into the Lovable chat, exactly as written.
  2. When it finishes, ask Lovable to show the diff of public/scale-quiz-embed.html, or open the file and check by eye:
    • The five resultPages URLs now point to /scorecard/operator, /scorecard/juggler, /scorecard/stabiliser, /scorecard/strategist, /scorecard/scaler.
    • The line containing webhook-trigger/e90c5cb1 is untouched.
    • The questions = [ block is untouched.
  3. Check the three consistency fixes in preview:
    • /scorecard: the "Get the book on Amazon" footnote link under the staircase image is gone, and the caption reads "15 questions. About 3 minutes."
    • /results: both assessment CTAs now read "Take the free 3-minute S.C.A.L.E. Assessment".
    • /podcast and /mentoring: any assessment duration mention says "3 minutes" (not 5, not 2).
  4. Publish.

Done when

  • The resultPages mapping shows only denlennie.com paths; no thescalemethodbook.com URLs anywhere in the file.
  • Webhook line and questions block unchanged.
  • The three consistency fixes are visible on the live site.
  • Smoke test: in a private browser window, complete the quiz at denlennie.com/scorecard with a test name and email, and land on one of the new result pages.

If something goes wrong

  • The quiz breaks (questions do not advance, or submitting hangs): revert the change in Lovable immediately. The old redirect is a leak, not an outage; a broken quiz is an outage. Then message Den.
  • You land on a thescalemethodbook.com page after the quiz: the file was cached or the mapping edit missed a stage. Hard-refresh, retest, and check all five entries in the mapping.
