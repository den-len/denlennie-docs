Scorecard funnel runbookSTEP 01

Build the five result pages.

Create the five S.C.A.L.E. Assessment result pages on denlennie.com using the prepared prompts. You are pasting prompts and checking output, not writing copy or designing.

System Lovable (denlennie.com project) Time 60–90 minutes You need Editor access + the prompt pack from Den ("scorecard-results-lovable-prompts")

Before you start

  1. Open the Lovable project and confirm the site preview loads.
  2. Open the prompt pack. You will use Prompts 1 through 6 in this step. Prompt 7 belongs to Step 02, do not paste it yet.
  3. Lovable publishes when you tell it to. Build and check everything in preview first.

Steps

  1. Paste Prompt 1 (the shared template) into the Lovable chat, exactly as written. Wait for the build.
  2. In the preview, open each of the five new routes: /scorecard/operator, /scorecard/juggler, /scorecard/stabiliser, /scorecard/strategist, /scorecard/scaler. Each should show the template with the site's normal header and footer. Placeholder content is fine at this point.
  3. Paste Prompt 2 (Operator copy). When it finishes, read the preview page against the prompt word for word. Lovable sometimes "improves" copy. If a single word differs, reply: "The copy I gave you is final. Restore it exactly, including punctuation."
  4. Repeat for Prompts 3, 4, 5 and 6 (Juggler, Stabiliser, Strategist, Scaler). One prompt at a time, check each before the next.
  5. Click every button on every page in preview and confirm the destination:
    • Operator, Juggler, Stabiliser: primary → /growth-strategy-session, ghost → /free-chapter, quiet link → /book
    • Strategist: primary → /growth-strategy-session, ghost → /elite-consultation, quiet link → /book
    • Scaler: primary → /elite-consultation, ghost → /growth-strategy-session
  6. Check brand basics on one page (they share the template, so one is enough): navy hero, orange only on the stage word, the staircase highlight, the pull-quote rule and the primary button; Poppins headings; no em dashes anywhere.
  7. Check mobile view in Lovable's responsive preview: single column, staircase graphic above the headline.
  8. View the page source of one result page and confirm it contains <meta name="robots" content="noindex">.
  9. Publish.

Done when

  • All five routes load on the live site (not just preview).
  • Copy on all five pages matches the prompt pack word for word.
  • All buttons land on the correct live pages.
  • Noindex tag present.
  • Nothing else changed: homepage, /scorecard and /growth-strategy-session still look normal.

If something goes wrong

  • Lovable drifts or breaks another page: tell it to revert the last change (it keeps history), then re-run the single prompt that failed. Never ask it to "fix everything".
  • A prompt produces a wrong-looking page after two attempts: stop, screenshot it, send to Den on Signal with the prompt number.
