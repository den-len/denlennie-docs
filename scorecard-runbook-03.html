Scorecard funnel runbookSTEP 03

Prove the whole journey works.

Quiz to correct result page to correct next step, end to end, and the lead capture still landing in SceneOps. Nothing ships on trust.

System A normal web browser + SceneOps (Contacts) Time About 30 minutes You need Steps 01 and 02 completed and published

How the quiz decides your stage

Every answer in the quiz is tagged to one of the five stages, and the answers are written in stage order: the first answer to each question is the Operator answer, the last is the Scaler answer. Picking the same position on every question forces that stage's result. That is how you test all five outcomes.

Steps

  1. Test all five outcomes. In a private browser window, take the quiz five times at denlennie.com/scorecard, using the name "QA Test" and findable test emails:
    Answers pickedShould land onTest email
    All first answers/scorecard/operatorqa-scale-operator@denlennie.com
    All second answers/scorecard/jugglerqa-scale-juggler@denlennie.com
    All third answers/scorecard/stabiliserqa-scale-stabiliser@denlennie.com
    All fourth answers/scorecard/strategistqa-scale-strategist@denlennie.com
    All last answers/scorecard/scalerqa-scale-scaler@denlennie.com
  2. Check the lead capture. In SceneOps, search Contacts for "QA Test". All five test contacts should be there. If they carry a tag or source from the quiz webhook, write down what it is; Step 06 needs it.
  3. Delete the five test contacts so they never enter a nurture sequence or pollute reporting.
  4. Click every button on every result page on the live site and confirm the destination loads: /growth-strategy-session (all five pages), /free-chapter (Operator, Juggler, Stabiliser), /elite-consultation (Strategist, Scaler), /book (quiet links).
  5. Old links, for reference. Open thescalemethodbook.com/results-page-juggler directly. Until Step 04 runs it will still show the old page. That is expected; do not panic and do not fix it here.
  6. Mobile pass. Take the quiz once on a phone and confirm the result page reads properly: single column, buttons full width, nothing overlapping.

Done when

  • Five stages, five correct landings.
  • Five test contacts appeared in SceneOps, then were deleted.
  • The webhook tag/source is written down for Step 06.
  • Every button on all five pages resolves to a live page.
  • Mobile result page looks right.

If something goes wrong

  • Wrong stage lands on wrong page: the resultPages mapping has a mismatched key. Back to Step 02.
  • Contacts do not appear in SceneOps: STOP. The webhook may have been disturbed. Revert the quiz file change in Lovable (this restores the leak but protects lead capture) and message Den immediately. Lead capture outranks everything else in this project.
